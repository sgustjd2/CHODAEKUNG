# UX Audit — 2026-09-08

Run via the `ux-review` skill. Live surfaces: landing, login, guest viewer (`/preview`, mobile 375) across all 8 themes. Editor **not** live-audited — it's behind the new login gate and the auditor can't self-authenticate (account creation/login is the user's action); audited from code + this session's hands-on.

**Summary.** The share-critical guest viewer is in good shape after this session's fixes (map buttons, RSVP-section submit, gallery lightbox, calendar .ics, custom-accent auto-contrast). The audit's main yield was a **theme-specific contrast bug in Cute** and an **onboarding snag from the new create-gate**, both fixed. The remaining open items are the intended-brand borderline (~2.5:1) default-coral accent and a couple of polish/architecture notes.
