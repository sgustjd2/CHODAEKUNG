# Workflow 04 — Final Review

Before a feature/phase handoff:

1. Review PRD acceptance criteria for the phase.
2. Review all affected Genspark references.
3. Check shared component consistency.
4. Test representative mobile widths.
5. Test desktop editor/dashboard widths where relevant.
6. Test keyboard interactions.
7. Test loading/empty/error states.
8. Test reduced motion.
9. Run repository verification.
10. Inspect the public invitation bundle/performance risks.
11. List unresolved deviations; never hide them.
