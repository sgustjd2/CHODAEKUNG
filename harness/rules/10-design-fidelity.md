# Design Fidelity Rules

1. Genspark is the visual reference when approved output exists.
2. Match hierarchy before decorative detail.
3. Match typography, spacing, sizing, radius, and layout before adding effects.
4. Do not add visual patterns not present in the approved system.
5. Preserve mobile-first invitation viewer composition.
6. Preserve the desktop editor's approved three-zone model when that design is selected.
7. Preserve the mobile editor's bottom-sheet interaction rather than shrinking desktop controls.
8. Compare every finished screen against its actual reference.
9. Record intentional deviations.
10. Never describe a screen as faithful if it was implemented without opening the available design reference.
