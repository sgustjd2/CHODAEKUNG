# Responsive Rules

## Priority

1. Published invitation on mobile
2. Mobile editor/PWA
3. Desktop editor
4. Dashboard/marketing responsive behavior

## Invitation viewer

- Never rely on hover-only interaction.
- Avoid fixed viewport assumptions that break mobile browser chrome behavior.
- Protect text/photo composition across common mobile widths.
- Treat safe-area insets when bottom actions are fixed.

## Desktop editor

Preserve the intended tool layout and mobile-preview proportions rather than stretching the invitation canvas to fill desktop space.

## Mobile editor

Use compact controls and bottom sheets. Do not squeeze desktop panels into narrow columns.
