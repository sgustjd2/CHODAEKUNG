# Accessibility Rules

- Use semantic elements before ARIA workarounds.
- Inputs require accessible names.
- Errors must be associated with fields.
- Icon-only controls require labels.
- Dialogs and sheets require correct focus handling.
- Focus indicators must remain visible.
- Ensure touch targets are practical on mobile.
- Meaningful images need appropriate alt text; decorative images should not create noise.
- Do not use color as the only signal for status.
- Honor `prefers-reduced-motion` for invitation effects.
- Maintain readable contrast even when user-selectable themes are supported.
