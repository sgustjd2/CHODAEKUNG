# Goal: Apply New Genspark Design Output

A new or revised Genspark design has been added.

Treat the latest approved Genspark output as the visual source of truth.

1. Inspect changed design artifacts.
2. Map affected tokens/components/screens.
3. Update `design-source-map.md`.
4. Update shared tokens/components first.
5. Propagate the change through dependent screens.
6. Do not patch duplicate page-local styles when the change belongs to a shared component.
7. Run verification.
8. Record meaningful deviations/migrations.
