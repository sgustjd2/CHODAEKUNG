# Expected Inputs

## Required

- `CLAUDE.md`
- `prd.md`
- source repository

## Strongly recommended

- Genspark high-fidelity screens
- Genspark component library/specification
- design tokens
- responsive behavior notes
- interaction notes
- mascot/icon exports

## Genspark input checklist

Before starting a major UI phase, try to have:

- [ ] desktop key screens
- [ ] mobile key screens
- [ ] editor screen
- [ ] published invitation viewer screens
- [ ] buttons/forms/tabs/dialogs/bottom sheets
- [ ] loading/empty/error states
- [ ] typography styles
- [ ] color palette
- [ ] spacing/radius/shadow rules
- [ ] icon set or icon style
- [ ] MOMO mascot exports
- [ ] app icon

Missing items do not automatically block work. Follow the fallback rules in `CLAUDE.md`.
